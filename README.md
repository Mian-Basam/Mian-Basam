# Hi, I'm Mian Basam Ahmad 👋

**Software Engineer @ [Educative](https://www.educative.io)** · Full-stack developer · Former university lecturer

I build web platforms and AI-powered tools for technical learning: course and content pipelines, internal automation, and developer-facing web apps. Before Educative, I spent five years teaching Data Structures, OOP, Databases, and Web Development at PUCIT, FAST, and UMT.

- **Content platforms & AI tooling:** LLM pipelines that generate and review courses, blogs, and mobile lessons
- **Full-stack web apps:** Next.js, React, Node.js/Express, Flask, MongoDB
- **Automation:** Playwright-based checks and scripts that save teams hours of manual work
- **Prompt engineering:** persona-driven writing and Socratic tutoring prompts
